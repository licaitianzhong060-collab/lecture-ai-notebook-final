# API仕様および制限事項（API_NOTES.md）

## 1. 採用モデル・エンドポイント
- **モデル名**: `gemini-3.5-flash`
- **用途**: 講義音声のマルチモーダル解析（文字起こし＆要約の同時生成）

## 2. 制限事項とデータ構造（公式仕様に基づく）
- **音声ファイルのサイズ制限**: インライン送信（Base64形式でのリクエストボディ埋め込み）を行うため、ファイルサイズは最大 **15MB〜20MB以下** に制限。本アプリでは軽量な講義音声（科学.m4a）を使用し、この制限をクリア。
- **データ型**: 音声データを `inlineData` としてMIMEタイプ（`audio/m4a` 等）と共にリクエスト構造に内包。
