# Lecture AI Notebook - 講義音声文字起こし＆要約ノートWebアプリ

Gemini API（gemini-3.5-flash）を使用した、超軽量・サーバーレスの講義音声文字起こし＆要約ノートWebアプリです。

## セットアップおよび使い方

### 1. 準備するもの
- 本リポジトリのコード一式（`index.html`, `index.css`, `app.js`）
- Google AI Studioで取得した「Gemini APIキー」
- 解析したい講義音声ファイル（.m4a などのオーディオファイル）

### 2. ローカルでの起動方法
1. 本リポジトリをクローンまたはZIPダウンロードします。
2. `index.html` をブラウザ（Google Chrome等）にドラッグ＆ドロップして開きます。

### 3. アプリの使い方
1. 画面上の入力欄に、ご自身の「Gemini APIキー」を入力します。
2. 「ファイルを選択」ボタンから、講義音声（例: `科学.m4a`）を読み込ませます。
3. 自動的に美しい波形アニメーションが走り、解析が始まります。
4. 数十秒後、画面上に「文字起こしテキスト」と、デジタルノート風にデザインされた「要約ノート」が同時に出力されます。
